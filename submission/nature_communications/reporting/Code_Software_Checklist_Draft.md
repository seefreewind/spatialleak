# Code and Software Checklist Draft V8

Code covers preprocessing, target-panel definition, split generation, benchmark models, statistical analysis, figure generation and source-data generation. Public repository: https://github.com/seefreewind/spatialleak. Version: v1.0.0. Archival DOI: https://doi.org/10.5281/zenodo.21881438. Core software versions are specified in `requirements.txt` and `environment.yml`: NumPy 1.26.4, pandas 2.3.3, SciPy 1.13.1, scikit-learn 1.6.1, Scanpy 1.10.3, AnnData 0.10.9, statsmodels 0.14.6 and PyTorch 2.8.0. PyTorch Geometric was not required for the native PyTorch GraphSAGE implementation. Evidence sources: `README.md`, `requirements.txt`, `environment.yml`, `scripts/`, `src/`, `tests/`.
